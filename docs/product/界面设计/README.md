## 设计边界

- 本地体验不连接平台，不产生真实访问；
- 平台版必须显式连接，显示 AIC/endpoint；
- 证书/私钥只在本机安全存储，不写进安装包；
- 界面里的案例、姓名、群聊均为虚构；
- 平台数据是 2026-10-21 的真实快照（法前哨 v1.1.0）。
