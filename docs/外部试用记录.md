## 每次试用后的三步核验

1. **平台侧**：`wt.ioa.pub` 后台/排行榜能看到这次调用；截图。
2. **任务库侧**：在 s1 查 inbound 行，确认 `senderId` 与 `endpoint_url`：

   ```bash
   ssh s1
   cd ~/witrelate
   ./.venv/bin/python - <<'PY'
   import sqlite3
   c = sqlite3.connect("file:.wit/leader/acps/aip-tasks.sqlite3?mode=ro", uri=True)
   cols = [d[1] for d in c.execute("pragma table_info(aip_tasks)")]
   for row in c.execute("select * from aip_tasks order by rowid desc limit 5"):
       d = dict(zip(cols, row))
       print(d.get("direction"), d.get("sender_id") or d.get("senderId"),
             d.get("remote_aic"), d.get("state"), d.get("task_ref"))
   PY
   ```

3. **产物侧**：`output/` 是否有本轮新增的 `verdict-*.json` / `ruling-*.json`；
   没有产物就不算成功。
