# 外部试用 · 复制粘贴样例

> 给试用方的最小操作包：**不用注册、不用装东西、不用上传文件**。
> 只做三步：打开平台 → 叮当搜「法前哨」→ 复制一段发过去，等结果截图。
> 案例都是虚构的，不要发真实姓名、身份证、住址。

---

## 一、直接转发这段话（最省事）

```text
在的话帮我点一下，3 分钟，不用注册、不用装东西：

1）打开 https://wt.ioa.pub/
2）在「叮当」里搜「法前哨」
3）把下面整段粘贴进去发送，等它出结果，截图发我

如果它说“等待输入”，把同一段再发一次就行。

—— 测试案例（虚构）——
请帮我分析一个名誉权场景：业主群里有人公开说我“私吞了小区维修基金的回扣”，
还说他手里有转账记录和聊天截图，但一直没有出示。我当晚在杭州出差，
有登机牌和酒店记录，但也没出示。请判断这句话的性质、目前能不能认定真假、
我该不该“自证清白”，以及下一步先做什么。不要替我下法律定性。
```

> 只发这一段就够，不要额外解释。通常 1–3 分钟出结果；
> 超过 5 分钟没动静，截个图发回来即可。

## 二、四个可选案例（一人发一个，别重复）

### A. 名誉权 / 业主群（默认，最稳）

```text
请帮我分析一个名誉权场景：业主群里有人公开说我“私吞了小区维修基金的回扣”，
还说他手里有转账记录和聊天截图，但一直没有出示。我当晚在杭州出差，
有登机牌和酒店记录，但也没出示。请判断这句话的性质、目前能不能认定真假、
我该不该“自证清白”，以及下一步先做什么。不要替我下法律定性。
```

**看点**：它应该说“目前无法判定”，并指出“谁主张谁举证”，而不是站队。

### B. 谣言核查 / 地震预言

```text
请帮我核查并给方向：家族群在传一张截图，说“某院士预测广东将发生 8 级以上大地震”，
截图有院士头像但没有原始链接。群里老人很慌。请判断这个说法可靠性，
告诉我该不该转发、现在要保留什么证据、下一步怎么做。不要编造来源；
无法确定就直说。
```

**看点**：它应该区分“有头像的截图”和“可核验的原始出处”，不拿截图当证据。

### C. 劳动维权 / 欠薪

```text
请给我一个劳动维权的准备清单：公司拖欠我两个月工资，没有签劳动合同；
我手里有微信工资转账记录、打卡截图、工作群聊天记录。请判断我先走协商、
投诉还是仲裁，分别要准备什么材料；哪些证据现在就要固定。
不要给我具体律师推荐。
```

**看点**：它应该给“先固定哪几类证据、走哪条路径”的方向，不编具体律师。

### D. 租房押金 / 证据保全

```text
请帮我看一个租房押金纠纷：合同约定“退租时验收无误后退还押金”，
房东以“墙面有轻微污渍”为由全扣押金，但入住时的照片我没保存。
请告诉我这种情况通常怎么处理、我需要补哪些证据、先协商还是直接投诉/起诉。
不要替我下结论。
```

**看点**：它应该先讲“补哪些证据”，而不是直接说“你能赢”。

## 三、试用方只需要做三步

1. 打开 <https://wt.ioa.pub/>；
2. 在「叮当」里搜 **法前哨**，点它 / 点“确认推荐组合并执行”；
3. 把上面任意一段**整段**粘贴到输入框，发送，等结果，截图。

> 不要只发“在吗”“帮我看看”这类话；法前哨需要正文才会开始。
> 如果它回“等待输入”，说明正文没送达，把同一段再粘贴一次。

---

## 四、截图截什么

- 最后一段结论（能看清“无法判定 / 不实 / 建议”等字样）；
- 顶部的智能体名「法前哨」；
- 有任务号/时间更好；没有也不影响。

---

## 五、给邀请人的记录口径

| 项 | 记什么 |
|---|---|
| 谁 | 昵称/团队（不要真名） |
| 哪段 | A/B/C/D |
| 结果 | 成功 / 等待输入 / 失败 |
| 任务号 | 平台/叮当显示的那串 |
| 截图 | 打码后放 `docs/外部试用证据/` |

> 这四段都是**文字案例**，不需要图片/音频/视频附件；
> 想测鉴伪的，另约时间，不要在这个“3 分钟包”里加附件。
