## 结论

1. **主控没有消失**：名称/法律类查询都能命中，`active=true`，endpoint 8445。
2. **AIC 查询不是精确查找**：Discovery 是语义检索；把 AIC 字符串丢进去，
   返回的是“语义上像”的其他 Agent。平台页面的“输入 AIC 查询在线状态”因此会
   给出假阴性。**查 AIC 用 registry 或 `tools.list_agents`，不要用 Discovery。**
3. **能力词查不到，是平台元数据问题**：主控 ACS 的 `description` 仍是 9/27 的
   “受理待研判文本，协调专家 Partner，并汇总输出社会危害性判定结论”，
   没有“事实核查/证据鉴伪/法律建议/线索受理”。所以按这些能力词搜不到它，
   但按“法律咨询主控/法律咨询/法律研判”能搜到。
4. **旧 `COUJXB...` 查不到是预期**：它是软废弃的煽动性识别 Partner，
   服务没起、不在主链、Discovery 不返回；不要拿它当“主控丢了”的证据。

## 对材料的用法

- 演示/截图用 **名称或法律类查询**（“法律咨询主控”“法律研判”），不要用 AIC 查询；
- 必要验证场景的“自动发现”证据，用 `法律咨询主控` 的 `acsMap` 返回 + 主控 endpoint；
- 如果希望“事实核查/网络裁判/证据鉴伪”也能搜到主控，需要更新 ACS 的
  `description`/skills —— 这会改指纹、需要重审，**初赛阶段不做**，复赛前再评估。

## 复跑

```bash
# 在 s1 上（只读）
python - <<'PY'
import httpx
URL = "https://wt.ioa.pub/discovery/acps-adp-v2/discover"
for q in ("法律咨询主控", "事实核查", "1.2.156.3088.1.BUPT.81M3FX.X1J5R5.HKBBAM.018M"):
    r = httpx.post(URL, json={"query": q, "limit": 20}, timeout=30.0)
    m = (r.json().get("result") or {}).get("acsMap") or {}
    print(q, len(m), [a.get("name") for a in list(m.values())[:5]])
PY
```
