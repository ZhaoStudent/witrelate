# 外部试用邀请（3–5 人）

> 目的：把“成功外部访问 = 2 次（仍只有 1 个外部账号）”变成可举证的**不同账号**真实使用，而不是自测。
> 这份文件是**给试用方看的**，也是我们自己记录证据的口径。
> 不要在邀请里出现学校名称、LOGO、指导教师信息。

---

## 1. 什么算“外部”

| 类型 | 算不算 | 判定 |
|---|---|---|
| 用**另一个 ACPs 账号**的 Agent 调用主控 | ✅ 外部 | inbound 行的 `senderId` 前 7 段 ≠ 本项目账号前缀 |
| 平台用户通过「叮当 / Agent Store」调用 | ⚠️ 平台用户调用 | 有平台任务号/截图；**单独计数**，不冒充“外部 AIC” |
| 我们自己用第二台机器/第二个角色调用 | ❌ 自测 | 同账号前缀；只算联调 |
| 本地 stub / 直调函数 | ❌ 不算 | 没有经过平台 |

**唯一硬证据**：`.wit/leader/acps/aip-tasks.sqlite3` 的 inbound 行 +
平台后台访问记录截图。没有这两样，就不算。

## 2. 三个可选场景（挑一个即可，3–5 分钟）

### 场景 A · 事实核查（最轻，推荐第一次）

给主控发：

```text
请核查这条说法，并说明依据：
「<一条公开可见、非针对个人的可疑说法>」
```

期望：主控发现 `网络裁判`，裁判走快车道或辩论道，产出 `ruling-*.json` /
`verdict-*.json`。**允许结论是“无法判定”**——那是诚实，不是失败。

### 场景 B · 图片鉴伪（需要一张图）

给主控发：

```text
请研判这条说法，并检查随图有没有篡改或拼接的痕迹：
「<说法原文>」
```

同时附上一张图片（`image/png` 或 `image/jpeg` 字节）。期望：证据链产出
`evidence-*.json`，报告里有线索等级、`caveat`、`not_run` 与免责声明。

> 建议用自己生成/公开授权的图片，不要用涉及真实个人的照片。

### 场景 C · 法律咨询（生活化纠纷）

给主控或 `法律咨询顾问` 发：

```text
我遇到一个纠纷，想先了解方向（不要求法律意见）：
<发生了什么、什么时候、在什么地方、涉及金额>
```

期望：`LegalAdvice`，包含 `situation_summary`、`applicable`、`advice`、
`cited_articles`、`capability_note`、`disclaimer`。**超范围时应如实说“能力不足”。**

## 3. 怎么调用（按试用方条件选）

### 方式 1 · 平台「叮当」（最省事）

> **不想写步骤？直接发 [复制粘贴样例](外部试用-复制粘贴样例.md)。**
> 里面有现成文案，对方只需搜「法前哨」、粘贴、等结果。

1. 打开 <https://wt.ioa.pub/>；
2. 在「叮当」里搜索 `法前哨` / `网络裁判`；
3. 把上面的场景文本发过去；
4. 把返回结果、任务号/时间截图发回。

> ✅ 2026-10-21 已验证：叮当按「法前哨」能找到主控（primary，`legal.issue_verdict`）。
> 如个别时候索引延迟搜不到，稍等再试；有自己 Agent 的试用方也可用新 AIC
> `1.2.156.3088.1.BUPT.81M3FX.6CKYE5.0ZV54U.0IPO` 直连 8445。
> ⚠️ Agent 程序化 `acps_discover` 的 ADP 索引可能还滞后：找不到时直接按 AIC 派发。
> 不要用旧 AIC `…X1J5R5…`（已软删除）。

> ⚠️ 如果叮当显示「法前哨等待输入」：说明它只收到了启动命令 / DAG 摘要，
> 没收到待研判正文。把原文直接粘贴到输入框再发一次；这不是故障，
> 是法前哨**不肯在没有正文时硬编结论**。带图片/音频的，把附件一起重新发。

### 方式 2 · 试用方自己的 ACPs Agent（最正式）

试用方需要有自己的 AIC + 客户端证书，向主控的 8445 端点发一次 JSON-RPC
（mTLS）。请求体模板见 [调用说明](aicomp/调用说明.md) §5.1；
把 `senderId` 换成试用方自己的 AIC，`dataItems` 换成场景文本。
如果带图片，用 `file` + `bytes`（base64），不要只给 URL。

> 这条路径会产生真正的跨账号 inbound 记录，是最有价值的外部访问。

### 方式 3 · 反诈演练场（仅演示，不计访问）

演练场监听在 s1 的 `127.0.0.1:8090`，没有公网开放；需要 SSH 隧道才能访问。
它不注册 ACPs，**不产生平台访问记录**，所以不计入“外部调用”。
如果试用方只想体验产品，可以单独约时间开隧道。

## 4. 邀请话术（可直接复制，按需改）

```text
同学你好，我在做 AIC 智能体互联的参赛作品（法律合规多智能体），
想请你帮我做一次真实外部调用测试，大约 3 分钟：

1) 打开 https://wt.ioa.pub/ ，用「叮当」搜索「法前哨」；
2) 把下面整段粘贴进去发送（不用改、不用上传文件）：

—— 测试案例（虚构）——
请帮我分析一个名誉权场景：业主群里有人公开说我“私吞了小区维修基金的回扣”，
还说他手里有转账记录和聊天截图，但一直没有出示。我当晚在杭州出差，
有登机牌和酒店记录，但也没出示。请判断这句话的性质、目前能不能认定真假、
我该不该“自证清白”，以及下一步先做什么。不要替我下法律定性。

3) 等它出结果，截图返回结果/任务号发我。
如果它说“等待输入”，把同一段再发一次就行。

这只是一次功能测试，不需要注册或付费；如果你也有 Agent 需要被调用，
我可以回测。测试内容不会用于任何对外发布，涉及个人的信息请先打码。
```

> 不想带上面这一长段？直接发 [复制粘贴样例](外部试用-复制粘贴样例.md)，
> 里面有 A/B/C/D 四段现成案例。

## 6. 试用方不该做的事

- 不要发真实姓名、身份证、手机号、住址、未公开的聊天记录；
- 不要用涉及现实中具体个人的诽谤/隐私材料；
- 不要把“无法判定”当成“系统坏了”；
- 不要把鉴伪报告当成司法鉴定结论；
- 不要为刷访问量重复空跑——平台访问量按真实任务计，重复空跑没有意义。
