## 四、🔴 比分数严重得多的一条：必要验证场景未通过

评分细则原文（`rules.txt` 第 45–46 行）：

> 「参赛团队须将作品智能体成功接入该平台，完成**注册、自动发现、跨端互联访问全流程验证**……
> **未完成平台验证的作品视为未通过比赛必要验证场景**。」

四步进度：

| 步骤 | 状态 | 证据 |
|---|---|---|
| ① 注册 | ✅ 完成 | 3 个 Agent APPROVED/active，有 AIC |
| ② 自动发现 | ❌ **未验证** | 代码里 `acps_discover` 只写在 Leader 的 instructions 里，**从未真正执行过** |
| ③ 跨端互联 | ❌ **未验证** | 端到端那条链路是 `local_pipeline.py` **本地直调**两个 Runtime，不是真实跨 Agent 调用 |
| ④ 访问 | ❌ **未验证** | 服务从未启动，平台访问记录为空 |

**这意味着：如果今天提交，很可能在进入评分前就被判为"未通过必要验证场景"。**
这条是**一票否决**性质，不占 110 分，但会让 110 分失去意义。

**开关只有一个**：把服务跑起来，完整走一遍 发现→互联→访问，并截图存证。
代码已就绪（`run_agent.py` 的 `serve_direct_partner` 路径 + Leader 的 `AipDelegationHooks`），
差的只是**执行 + 存证**，不是开发。
