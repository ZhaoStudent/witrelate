`incitement` 与 `harm` 两个角色。它们自 2026-10-02 起被**软废弃**（源 `SOFT_RETIRED`：
留代码、留平台注册，但**不部署、不进链路**）。链路里少了这两个角色，结论里就再没有
哪个字段能在下游产物原文里找到出处 —— 全部落进 `gaps`，如实列成"找不到来源"。

**这不是溯源表的缺陷**，是**它如实报出了链路变窄**。（如果它给个假的 ✅，那才是缺陷。）

**要恢复现场演示效果**：`incitement` / `harm` 重新启用**无需重走审核**，点名启停即可：
