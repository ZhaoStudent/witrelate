## 建议配文（可直接放 PPT/报告）

- **00**：不是“教你怎么吵架”，是“让你先经历一次被编排”。
- **03**：把“他知道什么、你知道什么、双方都知道什么”摊开——很多争论输在信息差，不是输在道理。
- **05**：左边证据层（数字夸张），右边修辞层（举证倒置/诉诸权威/诉诸情绪）；每一句都指回原话。
- **06**：最后不是一句“你要小心”，而是“下次遇到同类话术，具体怎么接”。

## 使用边界

- 这是**教学模拟**，指控方是虚构角色；截图里的话是模型生成，不是对任何真实个人的指控。
- 它不是法律意见；正式处理请咨询执业律师。
- 演练场是**进程内编排**、不注册 ACPs，**不产生平台访问记录**；材料里不要把它算进“平台访问量”。
