# 法前哨 · 5 分钟视频脚本

> 时长：5:00（含 10 秒收尾余量）  
> 画幅：16:9 / 1920×1080 或 4K / 30fps  
> 语气：冷静、克制、证据感；像一份“事前 30 分钟”的复盘，不像广告  
> 案例：虚构的“业主群维修基金回扣”场景；不出现真实姓名、学校名、真实聊天记录

---

## 一、我眼中的这支片子

这不是一支“AI 很厉害”的宣传片，而是一支**“事前 30 分钟”的复盘片**。

镜头始终贴着一个普通人：夜里十点，他/她的手指停在群聊输入框上，不知道回什么。技术不在前台炫耀，只在关键时刻露出证据：平台真的被调用、任务真的来自另一个账号、结论真的能回到任务库。

全片不喊“颠覆”，只说一件事：

> **在成为当事人之前，先把事实、证据、话术准备好。**

它不拍“打赢官司”，也不拍“AI 判案”。它拍的是：**你没有回骂，也没有自证；你先把该做的事做了。**

## 二、叙事节奏

| 时间 | 段落 | 作用 |
|---:|---|---|
| 0:00–0:35 | 夜里的群聊 | 把观众拉进具体处境 |
| 0:35–1:05 | 不是法律意见，是事前准备 | 定产品边界 |
| 1:05–1:35 | 四件事 | 给记忆点 |
| 1:35–2:20 | 演练场 | 让“信息差/话术”可见 |
| 2:20–2:55 | 平台发现 | 证明不是本地 demo |
| 2:55–3:25 | 平台四拍 + 外部任务 | 证明真实外部调用 |
| 3:25–4:00 | “无法判定” | 全片情绪落点 |
| 4:00–4:30 | 结构 | 证明不是模型拍脑袋 |
| 4:30–4:50 | 回到群聊 | 回到人 |
| 4:50–5:00 | 收尾 | 留下产品名 |

## 三、逐镜脚本

### 01 · 00:00–00:35｜夜里的群聊

**画面**

- 黑场 0.5 秒；手机在桌面上震了一下，屏幕亮起。
- 手机竖屏特写：微信群聊界面（虚构），顶部“业主群（48）”，时间 22:07。
- 消息逐条弹出：
  - “@你 有人在群里说你私吞了维修基金的回扣。”
  - “他说手里有转账记录和聊天截图。”
  - “群里已经有人开始骂了。”
- 镜头切到拇指停在输入框上；光标闪烁；没有字。
- 画面冻结 1 秒，出现一行小字：**“回骂？解释？还是先不说？”**
- 右下角始终标：**“虚构案例”**。

**旁白**

> 晚上十点，业主群突然有人@你。  
> “你私吞了维修基金的回扣。”  
> 他说手里有转账记录，有聊天截图。群里已经有人开始骂你。  
> 你手指停在输入框上：回骂？解释？还是先什么都不说？

**屏幕字**

- `22:07 / 业主群（48）`
- `虚构案例`
- `回骂？解释？还是先不说？`

**声音/转场**

- 房间底噪、手机震动、消息提示音；没有音乐。
- 最后 1 秒静音，硬切到标题。

**素材**

- 手机聊天 Mock（Figma/HTML 录屏，深色模式）。
- 桌面/手部 B-roll 1 条。

### 02 · 00:35–01:05｜不是法律意见，是事前准备

**画面**

- 黑场中打出白色字：**“在成为当事人之前”**。
- 标题浮现：**法前哨**；副标题：**面向法律纠纷“事前准备”的可审计多智能体系统**。

- 出现三行字，逐行亮起：

> 把事实弄清楚，把证据留下来，把话想好。

> 它不替你打官司，也不下法律结论。

**屏幕字**

- `在成为当事人之前`
- `法前哨`
- `事实 / 证据 / 话术`
- `不替代律师 · 不做法律定性`

**声音/转场**

- 低频 ambient 起，音量很低；标题出现时一记轻的 whoosh。
- 从黑场到米白，硬切或 6 帧白闪。

### 03 · 01:05–01:35｜四件事

**画面**

- 四张卡片依次出现：**事实、证据、法律方向、话术**。
- 每张卡片出现时，配一个极简的动作：
  - 事实：一张聊天截图被“拆”成命题；
  - 证据：一张图被放大到像素；
  - 法律：法条行被高亮；
  - 话术：对话气泡被分层。
- 四张卡片收拢成一条线，线连到“法前哨”主控。

**旁白**

> 它把一条可能变成纠纷的发言，拆成四件事：  
> 事实、证据、法律方向、话术。  
> 四件事，由不同的 Agent 协作完成；每一步都留痕。  
> 它不追求“替你赢”，它追求“你别在第一步就输”。

**屏幕字**

- `事实 / 证据 / 法律方向 / 话术`
- `每一步都留痕`

**声音/转场**

- 四声轻的卡片“嗒”；节奏与旁白对齐。
- 最后一句“别在第一步就输”后，留半拍。

### 04 · 01:35–02:20｜演练场：他不是证据多，是话术密

**画面**

- 体验应用录屏（真实 UI）：
  - 首屏 → 填写三桶信息（公开战场 / 对方的牌 / 你的底牌）；
  - 立案 → 诱导方发言 → 裁判介入；
  - 信息地图展开：`shared / theirs / mine` 三色；
  - 复盘页：证据层、修辞层逐条揭示。
- 在“信息地图”处停 2 秒，用细线标出：
  - “他声称有” vs “他没出示”
  - “你有，但没出示”
- 在“复盘”处放大一句：**“他不是证据多，是话术密。”**

**旁白**

> 先看演练场。  
> 你把知道的信息分三桶：群里公开的、对方声称的、只有你知道的。  
> 受理官立案，诱导方开始带节奏；裁判最后把证据层和修辞层一层层揭开。  
> 你第一次看到：对方不是证据多，而是话术密。

**屏幕字**

- `公开战场 / 对方的牌 / 你的底牌`
- `他声称有 ≠ 他拿得出`
- `他不是证据多，是话术密`

**声音/转场**

- UI 点击声、轻微键盘声；音乐保持很低。
- 揭示时一记低频“咚”，不要用惊悚音效。

**素材**

- `docs/aicomp/截图-体验应用/00-initial.png`
- `01-filled.png` / `02-accusation.png` / `03-info-map.png`
- `04-debate.png` / `05-reveal-top.png` / `06-reveal-bottom.png`

- 账号头像/姓名打码或裁掉。

> 演练完，你再把它交给平台上的法前哨。

> 叮当搜“法前哨”，派任务；

- 键盘输入声、点击声；音乐略微抬起。

### 08 · 04:00–04:30｜不是模型拍脑袋

**画面**

- 架构图简化动画：
  - 主控 → 裁判 / 证据 / 法律；
  - 主控(1) → 内层 Leader(2) → 叶子(3)；
  - `MAX_CHAIN_DEPTH = 3` 出现。
- 五个小方块依次亮起：**工具收敛 / 强提示 / 预算兜底 / 提交后清空 / 程序兜底**。
- 切到溯源表：`task_ref`、`event_seq`、每一跳、产物。
- 最后落到一句：**“每一步都能回到任务库。”**

**旁白**

> 支撑这句话的，不是一个大模型拍脑袋：  
> 两级嵌套、链深上限 3、五层终止；  
> 每一步落任务库，每个结论能回到哪一跳、用了什么材料。

**屏幕字**

- `MAX_CHAIN_DEPTH = 3`
- `五层终止`
- `任务库 → 溯源表`
- `每一步都能回到任务库`

**声音/转场**

- 节奏加快一点，但仍克制；五层方块每亮一个“嗒”。
- 架构图到溯源表用 match cut（同一条线）。

**素材**

- `docs/aicomp/架构图.png`
- `docs/aicomp/截图-溯源/02-trace-full.png`

## 六、拍摄与剪辑

- **画幅/帧率**：16:9，1920×1080 或 3840×2160，30fps；屏幕录制 60fps。
- **色彩**：夜聊冷蓝；产品 UI 米白；结尾深蓝。橙色只用于“注意/边界”，不要满屏。
- **字体**：思源黑体/微软雅黑，全片不超过两种；屏幕字 1 行，最多 12 字。
- **字幕**：中文硬字幕；每行 ≤16 字；关键词加粗/变色；不要让字幕挡住产品 UI。
- **声音**：配音 -16 LUFS；音乐 -25 dB 左右；关键句前留 0.5 秒静音；不要用“紧张悬疑”音效。
- **剪辑**：硬切为主；等待/加载用 2× 加速 + “等待”小字；不要花哨转场。
- **隐私/合规**：
  - 聊天案例虚构；不出现真实姓名、学校名、住址、身份证；
  - 平台账号头像/姓名打码或裁掉；
  - 外部 AIC 只显示前缀；不显示密码/证书；
  - 结尾保留“辅助研判，不构成法律意见”；
  - 不把“无法判定”剪成“失败”，也不把内部自测剪成外部调用。

## 七、30 秒预告（可选）

| 时间 | 画面 | 旁白/屏幕字 |
|---:|---|---|
| 0–5s | 群聊 @ + 手指停住 | “你私吞了维修基金的回扣。” |
| 5–12s | 四张卡片 | “事实、证据、法律方向、话术。” |
| 12–20s | 外部输出高亮 | “无法判定；谁主张谁举证。” |
| 20–25s | 平台/叮当 | “梧桐 ACPs 上，真实注册，真实调用。” |
| 25–30s | 深蓝收尾 | “法前哨：准备在成为当事人之前。” |

> 预告只用于群/朋友圈，不替代 5 分钟正片；正片必须完整展示注册、发现、互联、访问。

## 八、不要做的事

- 不要把 12 个 Agent 摆成一页“组织架构图”当主视觉；评委记不住。
- 不要喊“AI 判案”“一键胜诉”“替代律师”；这与产品边界相反。
- 不要用真实聊天记录/真实个人信息；不要靠卖焦虑。
- 不要把 95.45% 说成“准确率 95%”；正片不出现这个数字，留给答辩问答。
- 不要用第二个自己的账号冒充外部调用；外部任务要保留任务号。
- 不要用影视素材/网络图片伪造“平台界面”；所有平台画面必须真机录屏。
