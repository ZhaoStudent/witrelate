## 结论

1. **注册/审核没问题**：平台列表、详情页、服务器侧三处一致。
2. **按名称可发现**：叮当返回了主控的 AIC 与技能 `legal.issue_verdict`；这也是外部试用方该用的方式。
3. **AIC 查询框的“未查询到”是假阴性**：它把 AIC 丢给 Discovery 语义检索；实测按 AIC 查会返回无关 Agent。不要把那张失败截图当证据。
4. `04` 里的两条 `法律咨询主控（demo）` 是 09-29 已删除的历史记录（`APPROVED/已删除`、`PENDING/已删除/无AIC`），**不是当前主控**；当前主控是第一条 `[APPROVED/active]`。
