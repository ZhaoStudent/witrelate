## 1. 一句话定位

在梧桐 ACPs 平台（`wt.ioa.pub`）上，把一条可疑说法走完
**事实核查 → 多媒体证据鉴伪 → 法律建议 → 可追溯裁定** 的多智能体系统；
另有一个面向当事人的**反诈演练场**（进程内编排，不注册平台）。

它不是“法律问答机器人”，也不是“模型自己学会判断”；
它的核心是**可审计的协作链**与**不依赖模型自觉的交付护栏**。

## 3. 三条链路

```text
① 事实核查（跨进程 ACPs）
   leader(8445) → fact-judge(8448) → debate-pro(8446) / debate-con(8447)
   快车道：事实库对齐命中 / 经验库合格先例命中 ⇒ 跳过辩手，直接出裁定
   辩论道：无命中 ⇒ 正反方并发扇出 → 裁判裁定

② 证据鉴证（跨机 ACPs）
   leader(8445) → evidence-leader(8450, s1)
                    ├─ evidence-image(8449, s2)
                    ├─ evidence-audio(8451, s2)
                    └─ evidence-video(8452, s2)

③ 反诈演练（进程内，不走 ACPs）
   受理官 → 诱导方 ⇄ 当事人（真人） → 裁判揭示
   每局必须以揭示收尾；诱导方 traps 不进入公开视图。
```

`law-advisor` 与 `lead-intake` 是挂在主控下的叶子 Partner（链深 1），不发起委派。

## 5. 未验证 / 边界（不许说成已验证）

1. **成功的外部访问只有 1 次**（截至 2026-10-11 指标快照：268 条 inbound =
   264 自测 + 4 外部，其中 3 条非成功）。之后没有刷新过全量指标。
2. **95.45% 不是泛化准确率**：22 条人工基准、21 对；15 条“不实”+7 条“确有其事”；
   **没有“断章取义/无法判定”基准**；事实库与基准高度同源，检索成分大。
3. **MCP 桥接层不存在**：代码里是 MCP server（把鉴伪能力暴露给 MCP 客户端），
   不是设计文档里的 MCP↔Capability 桥接。
4. **反诈演练场不注册 ACPs**：不产生平台访问记录；它的价值是教学与演示，不计入访问量。
5. **证据鉴伪是技术线索，不是司法鉴定**：没有已知篡改/未篡改的 ground-truth 数据集；
   音频压缩格式、视频帧层能力有明确边界；报告里必须保留 `caveat` / `not_run`。
6. **平台侧脆弱性**：`wt.ioa.pub` 证书曾在 2026-10-15 过期；discovery 索引曾丢失；
   同账号并发登录会顶会话；这些不是本项目的 bug，但会影响现场演示。
7. **公平性遗留**：已注册 ACS 的 `provider.organization` 仍是
   `BUPT-LegalAgent-Demo`（历史注册，改动需重走审核）。**材料/视频/平台截图
   不要露出 provider 字段**；新模板 `.env.example` 已改成中性名，重新注册时用中性名。
